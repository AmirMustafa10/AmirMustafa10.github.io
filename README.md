Static portfolio website built around a calm, professional dark-blue visual system.

- V1-style hero and visual identity
- Fixed dark theme (theme switch removed)
- Responsive navigation
- Hero contact chips with hover states
- Core Stack placed directly below the hero/photo composition

- Professional About section
- Skills grouped by category with compact icons + names
- Project cards with Featured / Work in Progress states
